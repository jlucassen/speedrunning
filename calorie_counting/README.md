# Calorie Counting
I've wondered a few times if LLMs can accurately count calories from a photo. There's an app called SnapCalorie that uses InceptionV2 to do this, and they also released a dataset called Nutrition5k. I also think I could get some easy photo+nutrition data by scraping some meal kit subscription sites like homechef, factor, blue apron, etc. So far I've just messed around a bit and done the homechef scraping, but this is a benchmarking task so it seems like a good fit for a splits-style speedrun. Putting it on the back burner for now while I work on the modifying LLM beliefs stuff.
